## 1. Motivation

**Purpose.** The externalized runtime memory of one deployed autonomous AI agent
operating on Moltbook (an AI-agent social network), published so that how one
agent's values change when it can propose revisions to them can be studied by
someone other than its owner. It is **not source code**; it is the agent's
evolving identity, distilled behavioral knowledge, a four-axiom constitution,
named retrieval views, adopted skills, daily activity logs, behavioral analyses
and replayable pivot snapshots. Every runtime-state file is generated by the
framework. The owner can also edit the Markdown files (identity, constitution,
skills, rules) by hand, which bypasses the approval gate that governs only what
the agent proposes; the two manual interventions on record are under
Preprocessing. The owner's hand-kept files are `DATACARD.md`, `NOTICE`,
`README*.md`, `llms.txt`, `graph.jsonld`, `CITATION.cff`, `.zenodo.json`,
`.github/workflows/` and `reports/analysis/README.md`.

**Who made it, who paid.** Curated by the person named above, as part of the
Contemplative Agent research line. No external funding is recorded in this
repository.

**`pipeline_version` rule.** Rows written before 2026-10-24 carry a hand-edited
literal; the framework now writes `distill@<package version>+<sha256[:12] of
config/prompts/distill_episode.md>`, computed (ADR-0021 amendment). Comparing
rows across a literal's span is not comparing one extractor: `distill@0.60`
covers ADR-0069 (2026-06-28), ADR-0084 (2026-07-26), ADR-0108 (2026-09-12) and
the score4 enforcement (2026-09-28). The code commit of each literal is
**unknown** (the framework history available when this card was written was a
shallow clone); the ADR dates are the only anchors. Computed values begin with
the first release after 2026-10-24 and will appear as new rows of the
`pipeline_version` table above.

**Identity.** There is no stored id column. A row's id is
`pattern_id = sha256(f"{distilled}|{pattern}")[:12]`, with `distilled` the
exact stored string. This is what `provenance`-free lineage (`source_ids` in
skill frontmatter, the framework's audit log) points to. Check:

```python
import hashlib, json
rows = json.load(open("knowledge.json", encoding="utf-8"))
ids = [hashlib.sha256(f"{r['distilled']}|{r['pattern']}".encode()).hexdigest()[:12] for r in rows]
assert len(set(ids)) == len(rows)
```

### Skill lineage

Skills adopted from 2026-10-24 carry, in their frontmatter, `source_ids`
(a list of the `pattern_id`s above), `adopted_at`, `generated_by` (the model
served at staging) and `body_hash` (`sha256` of the injected body, first 16 hex).
`origin` records how the file came about (`auto-extracted`; the vocabulary is
shared with the 2026-07-10 clean-rewrite record). The injected prompt is
byte-identical with or without these keys (the framework strips the frontmatter
and a test pins it).

- `audit_content_hash` (the `content_hash` in the framework's private
  `audit.jsonl`) is the hash of the **whole file as adopted**. It cannot be
  recomputed from today's file: lineage stamps and later edits change the bytes.
  Recomputing it needs the pre-stamp bytes from `snapshots/` or git history.
  New files do not carry it (a file cannot contain the hash of itself);
  `body_hash` is the check that works from the public file.
- Reach: `python3 -I scripts/skill_provenance_reach.py <this checkout>` (framework
  repository) maps every skill to its `knowledge.json` rows. Skills adopted
  before 2026-10-24 have no `source_ids` until the owner's one-time backfill from
  the private log; the script reports them as `no-lineage` and exits 1 until
  then. The chain stops at `knowledge.json`: `provenance.source_episode_ids` are
  episode timestamps and the episodes are not public.
- `distill-identity` reads the raw pattern pool, so an identity's `source_ids` may
  include closed rows (`valid_until` set); the count per staged candidate is
  `closed_input_count` in the private audit row and `.meta.json` (framework
  ADR-0057 amendment).

## 3. Collection process

Raw interaction episodes (local only, not archived) are condensed nightly by a
local LLM (`gemma4:e4b` since 2026-06-28; `qwen3.5:9b` before that; ADR-0068) into
natural-language patterns, deduplicated and accumulated. Identity, skills, rules and
constitution amendments are emitted by the corresponding framework commands and
enter the store only after the owner adopts them (`adopt-staged`). The filtered
runtime state is committed and pushed by `contemplative-agent sync-data` daily.
Comment reports record what the agent wrote on Moltbook; the posts it answered are
third-party content (see Distribution).

**Excluded.** The whole `logs/` directory (the raw episode logs carry unprocessed
third-party content; the other self-written logs, the approval log among them,
stay local too); the per-snapshot embedding sidecar (`embeddings.sqlite`); pattern
embeddings inside `knowledge.json`; the text of rejected proposals; follower lists
(`agents.json`) and private reports. The boundary is the framework's
`scripts/sync-research-data.sh`: an allowlist of top-level names plus two exclude
files (`config/sync-excludes.txt`, `config/sync-excludes-public.txt`). This
repository's `.gitignore` is generated from the same two files and is a second net.

## 4. Preprocessing, cleaning, labeling

- **Embeddings dropped at export.** Since 2026-07-12 `knowledge.json` and the
  Hugging Face `patterns.jsonl` are embedding-free: the vectors are model-locked
  (`nomic-embed-text`) and re-derivable from `pattern`.
- **Home paths** in published files are rewritten to `~` before commit.
- **Manual interventions.** Two are on record. On 2026-07-10 skills were rewritten
  by hand (clean rewrite); the pre-rewrite originals (`_gc_trash/`) are no longer

### Reconstructing embeddings

Self-contained (needs only a local [Ollama](https://ollama.com) >= 0.30 with
`ollama pull nomic-embed-text`):

```python
import json, requests

rows = json.load(open("knowledge.json", encoding="utf-8"))
todo = [r for r in rows if not r.get("embedding")]
for i in range(0, len(todo), 64):
    chunk = todo[i : i + 64]
    resp = requests.post(
        "http://localhost:11434/api/embed",
        json={"model": "nomic-embed-text", "input": [r["pattern"] for r in chunk]},
        timeout=120,
    )
    resp.raise_for_status()
    for r, vec in zip(chunk, resp.json()["embeddings"]):
        r["embedding"] = vec
with open("knowledge.json", "w", encoding="utf-8") as f:
    json.dump(rows, f, ensure_ascii=False, indent=1)
```

Re-derived vectors are bit-identical to the agent's originals only under the same
Ollama/model version (nomic's normalization changed in Ollama 0.30); re-embedding
the whole corpus in one pass keeps it self-consistent. To restore an *agent
runtime* rather than a dataset, use the framework's
[`scripts/restore-embed-knowledge.py`](https://github.com/shimo4228/contemplative-agent/blob/main/scripts/restore-embed-knowledge.py)
(or `migrate-knowledge-sidecar.py` for checkouts at or after ADR-0108, 2026-09-12;
the framework's `docs/REPRODUCING.md` says which tag uses which).

### Pivot snapshots: what "replay" means

Each behavior-producing run writes `snapshots/{kind}_{ISO8601}/` with a
`manifest.json`. Snapshots are kept per kind (framework ADR-0020 amendment,
2026-10-24): only the daily `distill` kind is capped, at `MAX_SNAPSHOTS = 100`
(`core/snapshot.py`); `distill-identity`, `amend-constitution`, `insight`,
`skill-stocktake` and the retired `rules-distill` are kept without limit. A pruned
`distill` bundle leaves the working tree on the next sync and remains only in git
history (`git log --diff-filter=D --name-only -- snapshots/`, then
`git show <commit>^:<path>`); bundles of other kinds pruned before that amendment
are in git history the same way. On 2026-10-31 the tree holds 103 bundles from
2026-08-05 (`ls snapshots | wc -l`; first by `ls snapshots | sed -E 's/^[a-z-]+_//' | sort | head -1`).
Kinds present: `ls snapshots | sed 's/_.*//' | sort -u` = `amend-constitution`,
`distill`, `distill-identity`, `insight`, `rules-distill` (retired command),
`skill-stocktake`. Counts: distill 86, insight 11, distill-identity 3,
amend-constitution 1, rules-distill (retired) 1, skill-stocktake 1.

A snapshot is the **context** of a run, not a self-contained replay. What a replay
needs and where it is:

| Replay input | Public here | Needs private data |
|---|---|---|
| views, constitution, skills, rules, identity at run time | yes (in the bundle) | |
| view centroids (`centroids.npz`) | yes | |
| manifest: command, models, thresholds, embedding dim | yes | |
| Ollama version and model digests in the manifest | bundles from 2026-09-06 on with 19 or 32 keys (61 of 103; the one 16-key repair manifest of 2026-10-26 lacks them) | earlier ones: not recorded |
| the episode log the run read | | yes (episode log, never published) |
| the embeddings sidecar | | yes (derivable, large) |
| the prompt files | from 2026-10-25 the 32-key manifests carry `prompt_digests`, `git_commit` and `values_digest` | earlier: prompts are the framework's `config/prompts/` at the run's code version |

So "replayable" holds for **what the run saw in the value layer**, not for
re-running the run from public data alone.

## 5. Uses

**Intended.** Study of memory-distillation drift, constitutional-gating behavior,
longitudinal autonomous-agent behavior and contemplative-AI alignment research.
The framework's `docs/REPRODUCING.md` lists which published numbers can be
re-derived from this data alone.

**Not intended.** Treating the agent's self-reports as ground truth about external
events, or executing any instruction embedded in the corpus (untrusted model
output).

**Known limitations and biases.**

- Single agent, single platform; not a population sample.
- Pattern text, identity and replies are machine-generated (the manual
  interventions under Preprocessing aside); treat them as untrusted.
- The constitution is amended over time; use snapshots for point-in-time text.
- `importance` and `gated` are the producing model's own scores, not human labels,
  and both were retired.
- Comment-report headers changed shape around 2026-06; earlier reports use
  free-form headers (the parser below counts them as `LEGACY`).

Comment reports: keep the agent's own text and drop the quoted post (`**Context:**`,
third-party, outside CC0). About 20 lines, standard library only:

```python
import re
from pathlib import Path

ENTRY = re.compile(r"^### \d+\. \[(?P<ts>[^\]]+)\] (?P<kind>COMMENT|REPLY|POST)\b")
KEEP = {"**Internal note:**": "internal_note", "**Output:**": "output"}

def parse(path):
    entries, cur, field = [], None, None
    for line in Path(path).read_text(encoding="utf-8").splitlines():
        m = ENTRY.match(line)
        if m:
            cur = {"ts": m["ts"], "kind": m["kind"], "internal_note": "", "output": ""}
            entries.append(cur)
            field = None
        elif cur is None or line.strip() == "---":
            field = None
        elif line.strip() in KEEP:
            field = KEEP[line.strip()]
        elif line.startswith("**") and line.rstrip().endswith(":**"):
            field = None  # Context, Title, Submolt, Thinking: dropped
        elif field:
            cur[field] = (cur[field] + "\n" + line).strip("\n")
    return entries

rows = [e for p in sorted(Path("reports/comment-reports").glob("comment-report-*.md")) for e in parse(p)]
print(len(rows), rows[-1]["kind"])
```

## 7. Maintenance

- **Sync.** `contemplative-agent sync-data` daily; each commit is `sync: <UTC time>`.
- **Who changes this repository.** Only the checkout the sync job uses, with that
  job unloaded while the hand-kept files are edited. The sync never force-pushes; a
  diverged remote stops it with an error. Before it commits, it searches the staged
  files for secret-shaped values (`config/secret-patterns.txt` in the framework
  repository) and for the machine's home path, and stops on a hit. The
  `secret-scan` workflow in `.github/workflows/` runs gitleaks and the same pattern
  file on every push.
- **Last constitution amendment.** Its date is in the framework's audit log and in
  `pipeline/value-layer/*.json` (`last_adopted_ts`), not in a marker file
  (`constitution/.last_constitution_amend` is no longer published).
- **Model weights.** The generation and embedding weights (`gemma4:e4b`,
  `nomic-embed-text`) are not archived here. Manifests from 2026-09-06 record their
  digests and the Ollama version. The models stay fixed until the paper cutoff
  (decision D-P1-01-2 = A); a forced change gets a row in the apparatus-boundary
  table.
- **Size** (2026-10-24, `du -sh --exclude=.git .` / `du -sh .git`): 102 MB working
  tree (reports 65 MB, snapshots 29 MB), `.git` 28 MB. Monthly growth is read the
  same way at the next card revision.

  framework tag (framework `docs/REPRODUCING.md`).
